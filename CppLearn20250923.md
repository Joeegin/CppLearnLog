## atomic的使用与理解

### 基本概念理解：

1. 理解std::atomic是C++11中引入的用于提供原子操作的类型模板，能够确保在多线程环境下对单个变量的操作是原子的，即不可被中断。

### 原子操作的使用：

1. 能够使用std::atomic类型来声明原子变量。

2. 能够使用std::atomic提供的原子操作，如load(), store()等。

3. 理解缓存一致性

   **缓存一致性**是指当多个处理器核心都有各自的缓存时，如何保证它们看到的内存数据是一致的。

   **问题场景**：

   - 核心A和核心B都缓存了变量X
   - 核心A修改了X，但修改只写入了自己的缓存
   - 核心B读取X，得到的是过期的值

   **解决方案**：通过缓存一致性协议（如MESI）来维护数据一致性。

4. 掌握MESI协议

   MESI是缓存一致性协议的一种，将缓存行状态分为四种：

   | 状态          | 描述                 | 其他核心能否读取   | 当前核心能否写入 |
   | :------------ | :------------------- | :----------------- | :--------------- |
   | **M**odified  | 已修改，与内存不一致 | 需要先写回内存     | 可以直接写入     |
   | **E**xclusive | 独占，与内存一致     | 无其他缓存副本     | 可以直接写入     |
   | **S**hared    | 共享，与内存一致     | 其他核心也有缓存   | 需要先获取独占权 |
   | **I**nvalid   | 无效，缓存数据过期   | 必须从内存重新加载 | 需要先获取独占权 |

   **工作流程**：

   - 当核心要写入缓存行时，必须确保处于M或E状态
   - 如果处于S状态，需要先发送"无效化"信号给其他核心
   - 其他核心收到信号后，将对应缓存行标记为I

6. bool的读写，还需要atomic保证吗？为什么？

   需要，具体情况看代码

   ```C++
   bool flag = false;
   
   // 线程A
   flag = true;           // 看似简单的赋值
   
   // 线程B
   if (flag) {            // 看似简单的读取
       // do something
   }
   ```

   **潜在问题**：

   1. **撕裂读/写**：bool可能不是原子类型，在某些架构上可能被拆分成多个内存访问
   2. **编译器优化**：编译器可能重排指令，破坏预期的执行顺序
   3. **缓存一致性**：没有内存屏障，修改可能对其他线程不可见
   4. **CPU重排**：处理器可能为了性能重排内存操作

7. 什么场景下使用锁？什么场景下使用原子变量？

   原子变量用于1）简单计数器；2）标志位控制；3）无锁数据结构，比如无锁队列

   **适合原子变量的情况**：

   - 简单的读-修改-写操作（递增、标志位切换）
   
   - 性能要求极高的关键路径
   
   - 需要实现无锁数据结构时
   
   - 操作可以单个原子指令完成
   
   锁用于1）保护复杂的数据结构；2）用于事务性操作，比如多个操作需要原子完成
   
   **适合锁的情况**：
   
   - 需要保护复杂的临界区（多个非原子操作）
   - 操作涉及多个不同的变量
   - 需要条件变量配合时
   - 代码可读性和维护性更重要时
   - 不熟悉无锁编程的情况下（锁更安全）

3. 理解work-stealing算法

   **基本概念**：

   - 每个工作线程有自己的任务队列
   - 当线程自己的队列为空时，可以从其他线程的队列"偷"任务
   - 减少竞争，提高CPU利用率

   **算法特点**：

   - **本地优先**：优先处理自己队列的任务
   - **随机偷取**：随机选择目标队列，避免热点
   - **后进先出**：偷取时从队列尾部取任务（最近添加的）

4. 优化线程池，添加work-stealing能力。

   贴一个ds给的代码示例，后续慢慢研究。

   ```C++
   #include <deque>
   #include <random>
   #include <atomic>
   
   class WorkStealingThreadPool {
   private:
       std::atomic<bool> stop{false};
       std::vector<std::thread> workers;
       
       // 每个线程有自己的任务队列
       std::vector<std::deque<std::function<void()>>> thread_queues;
       
       // 使用thread_local变量标识线程索引
       static thread_local int my_index;
       static thread_local std::deque<std::function<void()>>* local_queue;
       
       std::mutex queue_mutex;
       std::condition_variable condition;
       
   public:
       WorkStealingThreadPool(size_t num_threads = std::thread::hardware_concurrency()) {
           thread_queues.resize(num_threads);
           
           for (size_t i = 0; i < num_threads; ++i) {
               workers.emplace_back([this, i]() { worker_thread(i); });
           }
       }
       
       ~WorkStealingThreadPool() {
           stop = true;
           condition.notify_all();
           for (auto& worker : workers) {
               if (worker.joinable()) worker.join();
           }
       }
       
       template<typename F>
       void submit(F&& f) {
           // 随机选择一个队列提交任务，实现负载均衡
           static thread_local std::random_device rd;
           static thread_local std::mt19937 gen(rd());
           std::uniform_int_distribution<size_t> dist(0, workers.size() - 1);
           
           size_t index = dist(gen);
           std::lock_guard<std::mutex> lock(queue_mutex);
           thread_queues[index].push_back(std::forward<F>(f));
           condition.notify_one();
       }
       
   private:
       void worker_thread(int index) {
           my_index = index;
           local_queue = &thread_queues[index];
           
           while (!stop) {
               std::function<void()> task;
               
               // 1. 先尝试从本地队列获取任务
               if (pop_task_from_local_queue(task)) {
                   task();
                   continue;
               }
               
               // 2. 尝试从其他队列偷取任务
               if (steal_task_from_other_queue(task)) {
                   task();
                   continue;
               }
               
               // 3. 等待新任务
               std::unique_lock<std::mutex> lock(queue_mutex);
               condition.wait(lock, [this]() { 
                   return stop || has_any_task(); 
               });
           }
       }
       
       bool pop_task_from_local_queue(std::function<void()>& task) {
           if (local_queue && !local_queue->empty()) {
               task = std::move(local_queue->back());
               local_queue->pop_back();
               return true;
           }
           return false;
       }
       
       bool steal_task_from_other_queue(std::function<void()>& task) {
           static thread_local std::random_device rd;
           static thread_local std::mt19937 gen(rd());
           
           for (size_t i = 0; i < workers.size(); ++i) {
               size_t victim = (my_index + i) % workers.size();  // 随机化偷取顺序
               if (victim == my_index) continue;
               
               std::lock_guard<std::mutex> lock(queue_mutex);
               if (!thread_queues[victim].empty()) {
                   task = std::move(thread_queues[victim].front());  // 从头部偷取
                   thread_queues[victim].pop_front();
                   return true;
               }
           }
           return false;
       }
       
       bool has_any_task() const {
           for (const auto& queue : thread_queues) {
               if (!queue.empty()) return true;
           }
           return false;
       }
   };
   
   // 初始化thread_local变量
   thread_local int WorkStealingThreadPool::my_index = -1;
   thread_local std::deque<std::function<void()>>* WorkStealingThreadPool::local_queue = nullptr;
   ```

   

5. 优化线程池能力，异步执行任务，并能获取其任务执行的返回值。

   参考下面的代码。

下面是一个异步线程池简单实现，未添加work-stealing算法

```C++
#include <iostream>
#include <vector>
#include <thread>
#include <queue>
#include <condition_variable>
#include <future>
#include <mutex>
#include <functional>

class ThreadPool {
public:
    explicit ThreadPool(int n = 5): stop_(false) {
        for (int i = 0; i < n; i++) {
            workers_.emplace_back([this] {
                while (true) {
                    std::function<void()> task; {
                        std::unique_lock<std::mutex> lock(mutex_);

                        //等待条件，已经停止或者任务队列没有任务
                        cv_.wait(lock, [this] {
                            return stop_.load() || !tasks_.empty();
                        });
                        //判断一下，关闭线程池时，没有任务遗留时退出
                        if (stop_.load() && tasks_.empty()) {
                            return;
                        }
                        //取出任务
                        task = std::move(tasks_.front());
                        tasks_.pop();
                    }
                    //执行任务
                    task();
                }
            });
        }
    }

    ~ThreadPool() {
        stop();
    }

    void stop() { {
            std::lock_guard<std::mutex> lock(mutex_);
            stop_ = true;
        }
        //通知所有线程
        cv_.notify_all();
        //等待所有线程执行完任务
        for (auto &worker: workers_) {
            if (worker.joinable()) {
                worker.join();
            }
        }
    }

    template<typename R, typename... Args>
    auto AddTask(R &&r, Args &&... args) -> std::future<std::invoke_result_t<R, Args...> > {
        //重命名返回类型
        using return_type = std::invoke_result_t<R, Args...>;
        //如果线程池已经关闭，不允许提交任务了
        if (stop_.load()) {
            throw std::runtime_error("Task stopped");
        }
        //将任务封装进packaged_task，通过bind绑定函数和参数
        auto task = std::make_shared<std::packaged_task<return_type()> >(
            std::bind(std::forward<R>(r), std::forward<Args>(args)...)
        );
        //获取返回值
        std::future<return_type> res = task->get_future(); {
            std::lock_guard<std::mutex> lock(mutex_);
            //通过lambda表达式进行类型擦除，让任务队列保存lambda表达式
            tasks_.emplace([task]() {
                (*task)();
            });
        }
        cv_.notify_one();
        //这里直接返回future，不使用智能指针，需要共享结果的情况下可以用智能指针
        return res;
    }

private:
    std::vector<std::thread> workers_;
    std::queue<std::function<void()> > tasks_;
    std::mutex mutex_;
    std::condition_variable cv_;
    std::atomic<bool> stop_;
};

int func(int a, int b) {
    return a + b;
}

int main() {
    ThreadPool pool(5);
    auto future1 = pool.AddTask([] {
        std::this_thread::sleep_for(std::chrono::seconds(1));
        std::cout << "第一个任务" << "\n";
    });
    auto future2 = pool.AddTask(func, 2, 2);

    std::cout << future2.get() << "\n";
    future1.get();

    return 0;
}
```



[42. 接雨水](https://leetcode.cn/problems/trapping-rain-water/)

给定 `n` 个非负整数表示每个宽度为 `1` 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

```C++
class Solution {
public:
    int trap(vector<int>& height) {
        int ans = 0;
        std::stack<int> stk;
        int n = height.size();
        for (int i = 0; i < n; ++i) {
            while (!stk.empty() && height[i] > height[stk.top()]) {
                int top = stk.top();
                stk.pop();
                if (stk.empty()) {
                    break;
                }
                int l = stk.top();
                int w = i - l - 1;
                int h = min(height[i], height[l]) - height[top];
                ans += w * h;
            }
            stk.push(i);
        }
        return ans;
    }
};
```
